# tutor.writing — 아이들을 위한 매일 Writing 튜터 에이전트

미국 8학년·6학년 아이들이 **매일 읽는 책**을 바탕으로 영어 글쓰기를 연습하고,
학년 수준에 맞는 피드백을 받으며, 게임처럼 레벨을 올려가는 Claude Code 기반
튜터입니다. 모든 기록은 md 파일로 저장됩니다.

## 사용법 (How to use)

이 리포지토리에서 Claude Code를 실행한 뒤:

| 명령 | 언제 | 무엇을 하나 |
|------|------|-------------|
| `/setup` | 처음 한 번 (아이별) | 이름·학년·읽는 책을 등록하고 프로필 생성 |
| `/today` | 매일 독서 후 | 템플릿 추천 → **예시 글 먼저 보여주기** → 아이가 작성 → 즉시 피드백 → XP 지급 → md 저장 |
| `/weekly` | 주 1회 | 일주일치 글을 모아 성장 리포트 작성 (부모님용 한국어 요약 포함) |
| `/progress` | 아무 때나 | 레벨·XP·스트릭·배지 현황 보기 |

### 하루 5~15분 플로우

1. 아이가 오늘 읽은 책과 분량을 말합니다. **조금 읽은 날도 괜찮습니다** —
   분량에 맞는 템플릿(예: Quick Write 3-2-1)이 따로 있습니다.
2. 튜터가 템플릿 2개를 제안하고, 아이가 고릅니다.
3. **같은 템플릿으로 쓴 예시 글을 먼저 보여줍니다** (6학년: *Hatchet*,
   8학년: *The Giver* 기준). 그 다음 아이가 자기 책으로 씁니다.
4. 피드백: 잘한 점 2가지 🌟 + 고칠 점 딱 1가지 🔧 + 보너스 도전 1가지 🚀.
   튜터는 절대 대신 써주지 않습니다.
5. XP 지급, 스트릭 갱신, 배지 확인 → 전부 md로 커밋.

## 포트폴리오 웹 (GitHub Pages)

아이들이 쓴 글(`## My writing`)을 Epic처럼 **책 표지 그리드**로 모아 보는 정적
웹사이트가 포함되어 있습니다. md 파일을 그대로 읽어 브라우저에서 렌더링합니다.

- **책별 보기** — 글을 쓴 책마다 표지 카드로 그룹핑 (기본 화면)
- **템플릿별 보기** — Summary, Golden Line 등 템플릿별 히스토리
- **타임라인** — 월별·날짜별 히스토리
- **Tutor feedback 토글** — 헤더의 스위치로 피드백 표시/숨김 (설정은 브라우저에 저장)
- 학생이 여러 명이면 상단 탭으로 전환

### 웹 퍼블리시 설정 (1회)

1. GitHub 리포지토리 → **Settings → Pages → Source**를 **GitHub Actions**로 변경
2. main 브랜치에 푸시하면 `.github/workflows/pages.yml`이 자동으로
   `manifest.json`(일기 목록 색인)을 생성하고 배포합니다.
3. 주소: `https://kyj5482.github.io/tutor.writing/`

매일 `/today` 세션이 커밋·푸시될 때마다 포트폴리오도 자동 갱신됩니다.

### 로컬에서 미리 보기

```bash
node scripts/build-manifest.mjs   # 일기 색인 생성
python3 -m http.server 8000       # http://localhost:8000 접속
```

  tutor.md           이 아이를 어떻게 가르칠지 — 실제 글 전체를 분석한 개인화 카드
  journal/           매일의 글 (날짜-템플릿.md) — 아이의 원문 그대로 보존

## 설계 원칙

- **예시 먼저, 매번 다른 책으로**: 처음 보는 템플릿은 어렵습니다. 잘 알려진 학년 수준
  책의 일부를 읽었다고 가정한 예시를 먼저 보여주고 시작합니다. 같은 책 예시가 반복되면
  아이들이 더 이상 읽지 않기 때문에, 학년별로 3권을 두고 **연속 두 세션 같은 책을 쓰지
  않으며**, 그날 아이가 읽는 책과 결이 맞는 쪽을 고릅니다.
- **지적이 아니라 예방**: 같은 실수를 일곱 번 지적하는 것은 가르치는 게 아니라 튜터의
  습관입니다. 글을 쓰기 **전에** 오늘의 주의 항목을 한 문장으로 알려주고, 저장하기
  **전에** 10초 점검을 합니다. 그래도 3세션 동안 고쳐지지 않으면 지적을 멈추고
  `lessons/`의 3분짜리 수업으로 **규칙 자체를 한 번 제대로** 가르칩니다.
- **아이마다 다른 방법**: 지아는 **귀**로 고치고(소리 내어 읽으면 스스로 잡아냄),
  재이는 **논리**로 고칩니다(규칙과 이유를 알려주면 적용함). 같은 실수라도 접근이
  다르며, 그 근거는 `students/<이름>/tutor.md`에 실제 글 분석으로 기록되어 있습니다.
- **분량 유동성**: 매일 읽는 양이 달라도 됩니다. 템플릿이 읽은 분량별로
  매칭되어 있어 짧게 읽은 날도 스트릭이 끊기지 않습니다.
- **단계별 상승**: 모든 템플릿에 Tier 1→2→3이 있고, 피드백은 항상
  "다음 한 걸음"만 요구합니다. 한 스킬을 3회가량 보여주면 Tier가 올라갑니다.
- **게임화**: XP, 레벨 10단계(Scribbler→Master Author), 스트릭 보너스
  (3/7/14/30일), 배지 12종. XP는 절대 깎이지 않습니다.
- **기록**: 모든 글과 피드백은 md로 커밋되어, 한 학기 뒤 아이의 성장을
  그대로 비교해 볼 수 있습니다.

## 포트폴리오 사이트 (5개 화면)

| 화면 | 하는 일 |
|------|---------|
| 📚 **My Library** | 읽은 책이 **시리즈별 서가**로 정리됩니다. 39 Clues 6·7·8·9·10권은 읽음, 1~5권은 빈칸으로 보여 무엇이 남았는지 한눈에. 책을 열면 그 책에 쓴 글이 **내 메모**로 모입니다 — 나만의 가상 도서관. |
| 🪜 **My Ladder** | 글쓰기 성장 사다리 7단계(일기 → 문단 → 근거 → **에세이** → 토론 → 비평 → 연구). 각 단계의 **예시 글**을 보고 **내가 목표로 삼을 단계를 직접 고릅니다.** 남은 단계와 "다음 한 걸음"이 숫자로 보입니다. |
| 🏅 **Stamp Book** | 스탬프 20종 · 카드 5장. **못 받은 스탬프도 진행도를 보여줍니다** — "템플릿 10개 전부"가 아니라 "3/10 · 남은 것: 예측, 골든라인, …". 숫자를 채우면 "Ready!"로 표시되어 튜터에게 확인을 요청합니다. |
| 🔎 **My Notes** | 지금까지 쓴 **모든 글을 검색**합니다. 인물 이름 하나로 예전에 쓴 생각을 다시 꺼내 쓸 수 있어요. |
| 📅 **Timeline** | 전체 기록을 최신순으로. (`?parent=true` 를 붙이면 주간 리포트 화면이 추가로 열립니다.) |

**성장이 보이는 구조**: `/today`가 사다리를 한 칸씩 올리고, `/weekly`가 목표에 얼마나
가까워졌는지 검증합니다. 목표는 **아이가 직접 고르며**, 튜터가 배정하지 않습니다 —
고른 목표는 동기가 되지만 배정된 목표는 숙제가 되기 때문입니다.

**🎤 소리 내어 읽기**: 글을 저장하기 *전에* Claude Code의 마이크 버튼을 눌러 소리 내어
읽으면 **+5 XP와 Voice 스탬프**를 받습니다. 반복되는 실수를 줄이는 가장 값싼 방법이라,
매일 지급합니다. 스스로 잡아낸 실수는 "실수"가 아니라 **깨끗한 글**로 기록됩니다.
- **반복 실수 추적 (Watch list)**: 아이마다 자주 하는 실수 최대 2개를
  프로필에 저장하고, 매일 세션에서 (특히 보너스 ACE 답까지) 확인합니다.
  3회 연속으로 실수 없이 쓰면 졸업 처리하며 축하합니다. 주간 "Focus skill"과
  별개로 돌아가, 사소한 실수가 몇 주씩 방치되지 않게 합니다.
