# Watch list — full rules

*The daily short version is in `CLAUDE.md`. This is the reference for adding, sharpening,
retiring, and escalating an item.*

---

The weekly "Focus skill" rotates, so a small mistake that keeps coming back can slip through the
cracks for weeks. The **Watch list** is a short, durable list of *this child's* specific repeated
errors, kept in the `## Watch list` section of `profile.md`. It runs *alongside* the focus skill —
it never uses up the weekly focus slot, which is reserved for a **growth** skill.

**Format**, one row per item (the portfolio parses it):

```
- [ ] <item> — clean streak: <n>/3 · e.g. "<their own slip>" → "<the fix>"
```

## The rules

- **Small and kind.** At most **2 items**, each one concrete and fixable — *"'and' between two
  doers → plural verb"*, not *"verb agreement"*. If a third would-be item appears, keep the two
  most frequent and let the others wait.
- **Say it before, not just after.** Name the item at the start of the writing and run the check
  before saving. An item that only ever appears in feedback is a scoreboard, not coaching.
- **Where it hides: the ACE answer.** The main entry gets a read-aloud pass; the bonus round
  usually doesn't. Always check **both**.
- **Advancing.** Clean in main **and** ACE → +1 to the streak, and say so in the 🌟 praise. A slip
  → reset to 0, and that item is the natural pick for the day's single 🔧. A slip the student
  catches themselves during the read-aloud counts as **clean** — that is the whole point.
- **Retiring.** At **3/3** mark it ✅ cleared, celebrate it that day and in the next weekly, and
  remove the row. Ending a months-old mistake is worth more than a badge.
- **Adding.** The weekly (or a daily session that spots a clear pattern) adds an item when the
  *same* concrete error appears in **2+ entries**. Say *where* it appeared — it is often the ACE.
- **Sharpen before you add.** If the slips keep landing on one narrow shape, rewrite the item to
  name that shape instead of adding a second row.
- **Untestable is not clean.** If the day's writing contained no compound subject at all, the item
  is untested — hold the streak, don't advance it, and note it. Four untestable sessions in a row
  means the *frame* is dodging the habit: put the target inside the **question** the student must
  answer, not in a blank they can route around.

## When a mistake won't go away — the escalation ladder

The Watch list is good at *spotting* a repeated mistake and was bad at *ending* one: Jaei was handed
the corrected sentence for compound subjects **seven times across two months** and his clean streak
never left 0/3. He was only ever shown the repaired sentence, never told the rule — and a repaired
sentence teaches you that one sentence.

| Times seen | What to do |
|-----------|------------|
| 1st | Fix it in the 🔧 slot. Move on. |
| 2nd | Add it to the Watch list. Name it before they write. |
| 3rd | **Sharpen** the item to the exact recurring shape. |
| **Stalled at 0/3 for three sessions** | **Stop correcting. Teach the rule once** from `lessons/`, then hand them a check they can run in 3 seconds. |

**Running a mini-lesson** (~3 minutes inside a normal session, +5 XP — see `/lesson` and
`lessons/README.md`): open by taking the blame (*"I've been giving you the fix instead of the rule
— that's on me"*), show the pattern **in their own sentences**, state the rule in one line, three
practice items out loud, then hand them the trick. Afterwards, if it slips, point at the **trick** —
never re-explain the rule.

## Match the tool to the error

| Error | Tool | Why |
|-------|------|-----|
| Endings (-ed / -s), tense, word choice, missing words | 🔊 **read aloud** | The ear catches it instantly |
| Agreement with *and* (*"Neville and Luna says"*) | 📖 **the rule, then the mic** | It *sounds* fine, so the ear can't find it |
| Quotation marks, possessive `'s`, periods | ✌️ **a count** | Marks are silent — you cannot hear punctuation |
| Structure (a missing paragraph, a missing move) | 🧱 **an empty container, before drafting** | Nobody retrofits a shape |

**Jia** is coached through **sound**, **Jaei** through **the rule and the reason**. Using the wrong
tool is how a mistake survives two months.
